# Relatório B0 do golden set C0

## 1. Objetivo

Este relatório registra a linha de base B0 do Knowledge OS.
Este relatório também registra a análise de erros de cada caso.
Os números brutos estão no arquivo [b0-c0-73570bb.json](b0-c0-73570bb.json).

Estes números não são metas.
O golden set tem 14 casos.
Um caso a mais ou a menos muda as médias de forma grande.
Use estes números para comparar configurações, não para aprovar o sistema.

## 2. Como reproduzir

1. Faça um clone de `issei/mauricio-site`.
2. Confirme que o clone tem o commit `73570bb`.
3. Execute a auto-verificação do golden set:

   ```bash
   kos bench check --suite bench/golden/c0.yaml --repo ../mauricio-site
   ```

4. Execute o benchmark num diretório de índice vazio:

   ```bash
   kos bench run --suite bench/golden/c0.yaml --repo ../mauricio-site \
     --policy policies/mauricio-site.json --home /tmp/kos-b0 --out b0.json
   ```

O resultado esperado da etapa 3 é "14 caso(s), 0 problema(s)".

## 7. Conclusões

1. O FTS5 recupera mais que as linhas de base sem índice. Recall@10 é 0,42 em B0, contra 0,10 em B0-grep.
2. O peso 2 no título aumenta o Recall@10, de 0,42 para 0,46. O mesmo peso diminui o Recall@1, de 0,19 para 0,11. A decisão sobre o peso precisa de mais casos.
3. O código é o ponto mais fraco: GS-CODE-002 e GS-CODE-003 falham na recuperação. O BL-15 ataca esta causa.
4. A citação é confiável: 0 `verified_exact` falso em 147 citações.
5. A abstenção ainda falha em 2 de 3 casos ABS. Isto depende do BL-18 e de mais casos (Q-14, Q-15).
6. A meta "P95 < 800 ms" da página pública não é uma medição. A busca local tem p95 de 86 ms. Este valor não serve como prova da meta, porque o corpus e a máquina são diferentes.

## 8. Limites

- O golden set tem 14 casos e 1 anotador. As médias são instáveis.
- As afirmações obrigatórias e proibidas são texto livre. O relatório JSON lista as afirmações produzidas em `human_review`. Uma pessoa precisa revisar esta lista.
- A métrica "evidência esperada citada" compara o trecho literal. Uma citação correta com outro recorte conta como erro.
- A CI não executa o golden set contra o corpus real. O teste `test_ben02_c0_against_real_corpus` executa só com `KOS_C0_REPO` definido.
